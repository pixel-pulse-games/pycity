Build PyCity on Windows

PyCity is written in C with the lightweight raylib library. The repository includes a Windows build script, build.bat, that makes a 64-bit build, a 32-bit build, or both. You don’t need a large IDE or a Linux layer.

Get the compilers

The script uses a portable toolchain called w64devkit. Download the version for each build you want to make.

  1. Open the w64devkit releases page.
  2. Download the 64-bit toolchain (w64devkit-x64-X.X.X.7z.exe) for the main build.
  3. Download the 32-bit toolchain (w64devkit-x86-X.X.X.7z.exe) if you also want the 32-bit build.
  4. Run each file. It is a self-extracting archive, so pick a permanent folder for it, for example C:\w64devkit and C:\w32devkit. Each one unpacks into a w64devkit folder inside the one you chose.

Set the paths

The first time you run build.bat, it finds no settings and starts a short setup.

  1. Open your PyCity folder and double-click build.bat.
  2. When asked, paste the path to each compiler’s bin folder, the one that contains gcc.exe and make.exe. Leave out quotation marks.
    • 64-bit: C:\w64devkit\w64devkit\bin
    • 32-bit: C:\w32devkit\w64devkit\bin
  3. Press Enter. The script saves your paths to a file named config.ini.

Choose a build

After setup, build.bat shows a menu.

  • 1 builds the 64-bit game (pycity-win64.exe) using raylib64/src.
  • 2 builds the 32-bit game (pycity-win32.exe) using raylib32/src.
  • 3 builds both, one after the other.

Change the paths later

If you move a compiler folder or mistype a path, run build.bat and press r to reset the configuration. The script deletes config.ini and starts the setup again.
